# Maquette pressing

Maquette d'une application de pressing connectée à WhatsApp : dépôts avec ticket, suivi du linge, message « prêt » au client, réponses automatiques. Le WhatsApp du client est simulé, les données restent dans le navigateur. Les noms et les prix sont des exemples.

En ligne : https://alexcruss.github.io/pressing-maquette/
